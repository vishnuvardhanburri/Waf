# Support Policy & Channels

Welcome to the PyWAF support portal. We provide support for community users, security engineers, and enterprise deployments.

---

## Support Matrix

| Category | Channel | Response Time SLA | Target Audience |
| --- | --- | --- | --- |
| **Security Vulnerabilities** | `security@pywaf.org` | 24 Hours | Security Researchers |
| **Bug Reports & Feature Requests** | [GitHub Issues](https://github.com/vishnuvardhanburri/Waf/issues) | 48 Hours | Open Community |
| **Community Q&A** | [GitHub Discussions](https://github.com/vishnuvardhanburri/Waf/discussions) | 3 Business Days | All Users |

---

## Supported Versions

We maintain active bug and security fix support for the latest release on `main` (`v1.x`). Upgrades to the latest release are strongly recommended.
